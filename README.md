# Portfólio — TiBelleck | Tecnologia e IA

Página única (`index.html`, sem build, sem dependências além de uma fonte do Google Fonts)
para portfólio de TI, foco em automação de processos e agentes de IA.

## Como ver

Abra `index.html` direto no navegador, ou acesse via GitHub Pages.

## Conteúdo

- **Hero** — headline, badge "aberto a oportunidades", CTAs (projetos / GitHub / contato)
- **Sobre** — trajetória real: loja de informática (hardware/impressoras) → autodidata →
  automação e agentes de IA
- **Skills** — agrupadas por automação/IA, linguagens, ferramentas e base técnica (hardware)
- **Projetos** — 5 cards:
  - *Extrator de Documentos Fiscais* — público, linkado
  - *Motor de Atendimento WhatsApp + IA* — privado, sem link
  - *Acompanhamento de Sinistro* — estudo de caso sem link (o código vive no repositório
    privado `jarvis-workspace`); destaca a decisão de arquitetura mais forte do projeto
    (roteamento determinístico por telefone, nenhum LLM decidindo o público)
  - *NEXUS* — linkado para o repositório público real
  - *JARVIS* — descrito sem link (repositório privado)
- **Contato** — e-mail e GitHub
