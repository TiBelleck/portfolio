Sobre

Da bancada de hardware para automação e IA

Autodidata. Antes de migrar para desenvolvimento e automação, tive uma loja de informática — venda e manutenção de hardware e impressoras. Foi ali que aprendi a resolver problema técnico direto com quem usa: sem manual, sem suporte de terceiros, no improviso que funciona.

Hoje trago essa mesma lógica prática para automação e agentes de IA: sistemas que integram WhatsApp, n8n, MCP e LLMs para eliminar tarefa repetitiva — com cuidado deliberado para o modelo de IA não decidir o que não deveria decidir, e não alucinar em cima de informação sensível.

Busco minha próxima posição em automação de processos e agentes de IA, onde experiência prática e disposição para aprender rápido pesam mais que caminho tradicional.

Extrator de Documentos Fiscais

público

Lê nota fiscal, boleto ou orçamento (foto ou PDF) e extrai os dados com OCR + LLM. Quem decide se o resultado pode ir para a planilha não é o modelo — é código que recalcula o que dá para recalcular.

Validação determinística antes de qualquer gravação: dígito verificador de CNPJ (inclusive o formato alfanumérico em vigor desde 31/07/2026) e CPF, dígito verificador da chave de NF-e, CNPJ do emitente conferido contra o embutido na chave, e soma dos itens contra o total declarado. 27 testes automatizados, pipeline validado contra a API real — que já pegou um bug de data e um rate limit de provedor antes de virar produto.
OCR LLM n8n Node.js

Motor de Atendimento WhatsApp + IA

privado

Motor de atendimento e vendas por WhatsApp construído sobre a Cloud API oficial da Meta — não biblioteca não-oficial, que arrisca o número comercial do cliente final com banimento. Multi-cliente desde a base: cada negócio tem seu número, sua personalidade de IA e suas conversas isoladas das demais.

Contenção de tentativa de manipular o comportamento do bot via mensagem do próprio contato, token de cada cliente fora do banco de dados, e recuperação de evento parado — processo que reinicia no meio do atendimento não deixa mais o contato sem resposta para sempre. 84 testes automatizados cobrindo os cenários que custam dinheiro ou confiança quando falham.
Python FastAPI WhatsApp Cloud API SQLAlchemy

Acompanhamento de Sinistro

estudo de caso

Automação de WhatsApp para acompanhamento de sinistro automotivo: avisa segurado, corretor e seguradora sobre o status do reparo antes de perguntarem — reduzindo ligação de quem só quer saber "como tá meu carro".

Decisão central: nenhum LLM decide o público ou monta a explicação técnica do reparo. O telefone identifica quem pergunta por comparação determinística de string, e o texto sai pronto de uma base de etapas — o modelo só redige. Em contexto de seguro, deixar o modelo inventar detalhe técnico é risco real.
n8n MCP WhatsApp Node.js
